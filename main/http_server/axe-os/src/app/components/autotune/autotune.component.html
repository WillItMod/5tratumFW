Before starting

Auto-tuning is experimental. Changing operating settings can cause instability, overheating, hardware damage, interrupted mining or financial loss. Use it at your own risk. To the extent permitted by law, the developer accepts no responsibility for issues or losses caused by tuning. This does not remove any rights that cannot legally be excluded.

Save your options before starting.

Starting requires fresh, valid sensors, ASIC counters and working cooling. The miner performs its own checks before changing settings.

The controller runs on the miner, including when this page is closed. Disabling requests restoration of the original pre-tuning backup. Restoration waits if conditions are unsafe; it never forces settings through a shutdown fault or clears that fault. Restarting never automatically starts another tuning run.
