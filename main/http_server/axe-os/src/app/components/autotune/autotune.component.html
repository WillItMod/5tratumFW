How the tuner learns

Small experiments · measured decisions
  1. 1ObserveCollect fresh counters and check cooling, errors and limits.
  2. 2Try a small stepRequest a nearby clock or voltage within your saved bounds.
  3. 3Settle & measureWait, then compare a complete valid window with the round reference.
  4. 4Keep, reject or back offUse the selected goal and noise margin; safety takes priority.

This is a local, bounded search, not a guaranteed global optimum. Normal search steps are {{ info.limits.frequencyStepMHz }} MHz or {{ info.limits.voltageStepMv }} mV. Safety backoff can be larger. Higher voltage can reduce timing errors only when power and temperature headroom allow it; reducing clock is another recovery route. Noisy comparisons need more evidence, not a claimed gain.

Continuous Off completes a bounded round and holds its result. Continuous On monitors for changed conditions and may reassess; it does not adjust constantly. Neither setting starts tuning after a reboot.

Before starting

Auto-tuning is experimental. Changing operating settings can cause instability, overheating, hardware damage, interrupted mining or financial loss. Use it at your own risk. To the extent permitted by law, the developer accepts no responsibility for issues or losses caused by tuning. This does not remove any rights that cannot legally be excluded.

Save your options before starting.

Starting requires fresh, valid sensors, ASIC counters and working cooling. The miner performs its own checks before changing settings.

The controller runs on the miner, including when this page is closed. Disabling requests restoration of the original pre-tuning backup. Restoration waits if conditions are unsafe; it never forces settings through a shutdown fault or clears that fault. Restarting never automatically starts another tuning run.
