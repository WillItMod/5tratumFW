# Gamma Beta 3 validation

Version: `5tratumFW-0.1.0-beta.3`. Development BETA, Gamma PCB identities 601 and 602 only.

Beta 3 adds direct Apply for a configured saved pool slot. Pool and tuning slots, settings-preserving journal, coordinated primary reconnection, and weekly pool switching were introduced in Beta 2. Power control remains the existing independent weekly mining scheduler. No automated tuning or new hardware operating point is introduced.

The Beta 2 paired app/WWW was installed on the Gamma 601 on 7 October 2026. Its 37 exported operating settings, including 550 MHz / 1150 mV, were retained; ten pool and ten tuning slots were returned by the bound API and accepted shares were observed. This is Beta 2 evidence, not a claim that Beta 3 has been installed.

Beta 3 build, browser and device verification is pending at this source checkpoint. The corresponding package records its exact build/source commit and paired image hashes. Results will be added here after those checks finish.

Gamma 602 is still on stock firmware. Physical OLED readability, sustained soak, fault injection and stock recovery are not established by host tests or the Gamma 601 installation. Per-ASIC independent mining and richer MUX coin/block metadata are not implemented in this Gamma image.
