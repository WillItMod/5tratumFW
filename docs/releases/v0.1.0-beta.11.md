# Gamma Beta11 — Ethernet test candidate

**Unpublished experimental candidate for Bitaxe Gamma PCB601/602, BM1370.** Based on ESP-Miner v2.15.4. The current public Gamma pair remains Beta10; NerdQAxe++ Beta8 and NerdOctAxe Gamma Beta6 are separate families.

Adds **Network → Enable wired Ethernet (W5500)**, off by default, with saved/startup status and an explicit save then restart flow. The original W5500 SPI driver uses GPIO40/39/41/42. Ethernet is preferred after obtaining an address, with saved Wi-Fi available for fallback. Network changes reconnect the existing pool session and preserve the miner's identity and operating settings.

The enabled accessory port is reserved from BAP, including self-test and module-absent paths. The flag is stored separately without shifting existing operating-journal field IDs. Existing device identity guards, clock/voltage/fan settings, pools and schedules remain in place.

Install only matching `esp-miner.bin` and `www.bin` from the same Gamma candidate. [Instructions and wiring](../gamma-ethernet.md) explain the module-specific supply requirements, recovery and disabling procedure. [Software validation](../validation-gamma-ethernet.md) records the tests and limits.

**No physical LAN module has been tested.** Real packet framing, link/DHCP, mining, fallback and Ethernet-only application/WWW OTA need qualification on the requester's adapter before promoting this candidate to the current public update.
