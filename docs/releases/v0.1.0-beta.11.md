# Gamma Beta11 — public experimental Ethernet BETA

**Public EXPERIMENTAL BETA for Bitaxe Gamma PCB 601/602, BM1370 only.** Based on ESP-Miner v2.15.4. [Download Gamma Beta11](https://github.com/WillItMod/5tratumFW/releases/tag/v0.1.0-beta.11). NerdQAxe++ Beta8 and NerdOctAxe Gamma Beta6 remain unchanged and are separate firmware families.

Adds **Network → Enable wired Ethernet (W5500)**, off by default, with saved/startup status and an explicit save then restart flow. The original W5500 SPI driver uses GPIO40/39/41/42. Ethernet is preferred after obtaining an address, with saved Wi-Fi available for fallback. Network changes reconnect the existing pool session and preserve the miner's identity and operating settings.

The enabled accessory port is reserved from BAP, including self-test and module-absent paths. The flag is stored separately without shifting existing operating-journal field IDs. Existing device identity guards, clock/voltage/fan settings, pools and schedules remain in place.

Install only matching `esp-miner.bin` and `www.bin` from this same Gamma release. [Instructions and wiring](../gamma-ethernet.md) explain the module-specific supply requirements, recovery and disabling procedure. [Software validation](../validation-gamma-ethernet.md) records the tests and limits.

**Software/build qualification only: Beta11 has not been installed on a miner, and no physical LAN module has been tested.** Real packet framing, link/DHCP, mining, fallback and Ethernet-only application/WWW OTA still need qualification on the requester's adapter. The release manifest retains `hardware_tested: false`; publication does not change that evidence.

On **5tratumOS 0.8.48 or later**, use **Firmware update → BETA → Check for updates** on the correct Gamma, select the model-labelled **Beta11 — experimental**, then **Install firmware → Confirm install** and wait for verification. Install over Wi-Fi with the adapter disconnected. Ethernet remains disabled until explicitly enabled under **Network** and applied at restart; follow [the full setup instructions](../gamma-ethernet.md). Future compatible releases are discovered without another OS update.

The published application/WWW pair and corresponding source were built from clean commit `e73cbc69b815b3f7e0a3a5af9266f605bb95a33b`. Later publication-documentation commits do not relabel the images. The corresponding-source archive preserves the prepublication wording present at build time; the current release notes and online guides describe public availability.

The previous physically checked [Gamma Beta10 pair](https://github.com/WillItMod/5tratumFW/releases/tag/v0.1.0-beta.10) remains available. To return to it, clear the Ethernet setting and save, power off and disconnect the adapter, then install both Beta10 files over Wi-Fi. No factory or NVS image is published.
