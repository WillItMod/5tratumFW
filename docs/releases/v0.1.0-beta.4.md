# 5tratumFW 0.1.0 Beta 4 — Gamma 601/602

Development BETA / GitHub prerelease. This paired application and WWW image accepts Gamma PCB identities 601 and 602 only. GT800, NerdQAxe, NerdOctAxe and other boards need separately qualified images.

The tuning confirmation now opens directly beneath the Review button you used, including within the selected saved-slot row. Opening Review sends no setting changes; Apply remains explicit. Changing manual inputs or leaving manual mode clears the earlier review. Ten named pools with direct Apply, ten named tuning slots and independent pool/power schedules remain included. This release adds no automatic tuning or fixed Low/Stock/Boost operating points.

Install both matched `esp-miner.bin` and `www.bin`, then restart once so the cached web version refreshes. Existing saved clock, voltage, fan, network and pool settings remain in place through compatible OTA. Follow [installation](../installation.md), [settings preservation](../settings-preservation.md), [profiles](../profiles-api.md), [power scheduler](../scheduler.md) and [recovery](../recovery.md). These are OTA images; no factory or NVS image is distributed.

See the [Beta 4 validation record](../validation-beta4.md) for exact build and device results. Gamma 602 remains physically untested. Gamma MUX information uses the legacy acknowledgment; richer QAxe coin/block context and independent per-ASIC mining are separate capabilities.

The pinned build and [GitHub validation run](https://github.com/WillItMod/5tratumFW/actions/runs/37645073267) passed at source/package commit `655e0d09ed3a25635bb59a01385659b1f28dd08d`: 121 frontend tests, all eight Gamma host entry points, 27 native OLED fixture views and the paired ESP32-S3 build/package checks.

On a Gamma 601, the matched Beta 4 pair booted with both versions matching and all **37 exported operating settings** retained, including this unit's saved **575 MHz / 1155 mV**. Existing profiles and schedules were unchanged; mining and **20 accepted shares** were observed. The live web interface showed the inline confirmation for a **575.25 MHz draft**, without applying that draft. These values are observations, not presets. Beta 4's device qualification covers the UI change, compatible OTA/settings preservation and a short mining check; the preceding Beta 3 power/pool scheduler tests remain separate evidence.

The image manifest records `hardware_tested:false` because it was generated before the later 601 bench check. This release note adds that later evidence without changing the packaged images/source. Gamma 602, sustained soak, physical OLED readability and fault/recovery testing remain unqualified. Low, Stock and Boost presets are design discussion only and are not implemented or verified.
