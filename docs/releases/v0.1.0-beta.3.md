# 5tratumFW 0.1.0 BETA 3 — Gamma 601/602

Development BETA / GitHub prerelease. Compatible image identities: Bitaxe Gamma PCB 601 and 602 only. Other Bitaxe boards, GT800, NerdQAxe and NerdOctAxe must use separately qualified firmware images.

Ten custom named pool slots now have a direct Apply button. Saving captures the current stored primary or fallback route without applying it; Apply changes only the selected destination. Ten named tuning slots, fine manual requests, the weekly pool-switch scheduler and independent power scheduler are included. Existing clock, voltage, fan, network and pool settings are retained during compatible OTA updates. No automated tuning or clock presets are applied.

Install the paired `esp-miner.bin` application and `www.bin` web image from this build. Follow [installation](../installation.md), [settings preservation](../settings-preservation.md), [profiles and pool switching](../profiles-api.md), [power scheduler](../scheduler.md) and [recovery](../recovery.md). These are OTA images; this release contains no factory or NVS image.

Read the [Beta 3 validation record](../validation-beta3.md) for exact build, browser and device results. Gamma 602 remains unflashed. The informational legacy MUX acknowledgment is separate from the QAxe's richer coin/block metadata. Independent per-ASIC jobs and multi-coin mining are not implemented in this Gamma image.
