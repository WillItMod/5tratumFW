# Bitaxe Gamma 601/602 Beta18: bounded restoration and clear recovery status

`5tratumFW-0.1.0-beta.18` is an experimental BETA. It does not add hardware-revision support.

The recovery owner now distinguishes physical restoration from tuning-quality admission. A failed or temporarily missing ASIC work sample cannot by itself prevent a safe original-settings restore. Fresh temperature, input/output voltage, regulator status, fitted-fan feedback, exact identity, immutable-backup integrity and physical clock/voltage confirmation remain required. Restoring an operator baseline with missing/high-error work measurements is reported with a quality warning; it does not claim that point is suitable for tuning.

Repeated Stop during an already requested recovery preserves that transaction. A manual pause stays paused unless the user explicitly requests Restore and resume. Recovery attempts have a bounded overall wait and report the actual phase/reason instead of displaying Restoring indefinitely. Blocked ownership is retained where needed to prevent an unverified fall-through to saved hardware settings; explicit retry or newer manual control remains possible.

Moderate ASIC-error rejection respects the full settling period and the counter interval before collecting a fresh confirmation streak. Severe error and physical protection checks retain their earlier response. The existing finite correction budget and error thresholds are unchanged.

The Tuning page shows restoration phase, elapsed time, remaining bound and quality warnings. It distinguishes a blocked recovery from active restoration and requires fresh controller activity for a new Start.
