# Gamma Beta16: report the active web-interface version

`5tratumFW-0.1.0-beta.16` targets Bitaxe Gamma601/602 with one BM1370. The manifest records the exact compiled source. Existing Gamma15 files remain unchanged.

## Fixed

Gamma15 reports the literal label `Unified` when using its application-bundled web interface. Overview incorrectly compares that label with the firmware version and warns that the files do not match, even after a correct application-only update. Re-uploading the same file or changing browsers cannot correct that reporting bug.

Gamma16 reads the version marker from the actual selected interface. In embedded mode it reads the embedded `/version.txt`, even if an older custom WWW partition exists. With custom WWW enabled and available it reads that interface's marker. Missing, malformed or compressed version markers remain unverified; they are never silently treated as matching the firmware. Genuine custom-interface mismatches still produce a warning.

The page distinguishes a version that could not be verified from two known versions that differ. This change does not alter mining, tuning, clocks, voltage, fan control, profiles, schedules or the original-settings backup.

## Update

For a normal manual Gamma update, install **esp-miner.bin** from this release. It includes its matching web interface. Keep power connected through the restart, then reload the page and confirm both reported versions are `5tratumFW-0.1.0-beta.16`. The separate matching **www.bin** is available for custom-WWW/compatibility workflows; it is not required for normal embedded operation. The existing 5tratumOS one-click updater continues installing and verifying the matched pair on the current MAIN/DEV channel.

No factory image, partition table or replacement NVS is included. A browser warning by itself is not a reason to erase settings or use USB recovery.

## Validation scope

Production-function host tests cover active embedded/custom selection, a stale unselected WWW, actual mismatches, absent or malformed metadata, CRLF, size bounds and allocation failures. Frontend tests preserve real mismatch warnings and distinguish unknown metadata. The release's build and installation evidence is recorded separately; software tests do not establish physical operation on every Gamma602 or adapter.
