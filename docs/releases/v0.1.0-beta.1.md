# 5tratumFW 0.1.0 BETA 1 — Gamma 601/602

**BETA / GitHub prerelease. Bitaxe Gamma PCB revisions 601 and 602 only.**

This release includes the 5tratumFW web interface, settings-preserving startup guard, weekly scheduler and manual ASIC power saving, Gamma OLED graphics and a strict informational MUX status receiver. MUX setup lives in Pool routing. Coinbase decoding defaults off; explicitly saved settings are retained.

Use `esp-miner.bin` for the application and matching `www.bin` for the web interface. Follow [installation](../installation.md), [settings preservation](../settings-preservation.md), [scheduler](../scheduler.md), [pool routing](../pool-routing.md) and [recovery](../recovery.md).

These are paired OTA images, not a factory image. Preserve each device's own configured clock and voltage. Other Bitaxe boards, GT800, NerdQAxe and NerdOctAxe are incompatible. Independent per-chip mining, autotuning, clock presets and authenticated native MUX control are not implemented or validated.

## Validation

See the [build-specific validation record](../validation.md) for the exact results. This BETA has not been installed on a physical miner. An earlier `5tratumFW-0.1.0-a1` app/WWW pair booted and mined on a Gamma 601; that observation does not validate this release. Gamma 602 remains unflashed. Physical OLED, pause/resume, scheduling, protection and recovery checks remain pending.

The matching MUX server status extension remains undeployed. Host tests validate the receiver contract; they do not establish a live advertised MUX session, routing correctness or payouts. No miner flashing or hub deployment occurred during preparation of this repository.
